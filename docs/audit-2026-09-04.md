# Audit dan modernisasi Bintang — 4 September 2026

## Cakupan

Audit mencakup seluruh aplikasi: arsitektur frontend, setiap rute dan pola layar,
aksesibilitas, autentikasi di browser, API, otorisasi berkas, bootstrap/migrasi
database, dependency dan lockfile, container, CI, serta dokumentasi operasional.

## Hasil perbaikan

### UI/UX

- Sistem visual diganti menyeluruh menjadi kanvas finansial berkontras tinggi:
  navigasi midnight, canvas netral, angka tabular, status emerald/rose, radius dan
  elevasi konsisten.
- Shell responsif sekarang memiliki sidebar desktop, rail tablet, dan dock mobile
  yang bersumber dari satu kontrak navigasi. Semua menu desktop tetap tersedia di
  mobile dan kebijakan akses menu tetap diterapkan.
- Login, dashboard, halaman data, master data, detail/form, laporan, state kosong,
  error, dan 404 menggunakan bahasa visual dan ritme yang sama.
- Fokus keyboard terlihat, target sentuh minimum diterapkan untuk perangkat
  pointer kasar, animasi menghormati `prefers-reduced-motion`, dan warna bukan
  satu-satunya pembeda status.
- Grafik dipisah sebagai chunk lazy dan tampilan data memakai ringkasan lebih dulu,
  lalu detail yang dapat ditelusuri.

Acuan desain: [Apple HIG — Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data),
[GOV.UK — Check answers](https://design-system.service.gov.uk/patterns/check-answers/), dan
[WCAG 2.2](https://www.w3.org/TR/WCAG22/).

### Correctness dan keamanan aplikasi

- Akses `/files` kini ditentukan dari proyek atau pemilik upload. OCR/ekstraksi AI
  hanya dapat dibuka pemilik atau admin; file orphan dan aset perusahaan dibatasi
  ke admin. MIME tersimpan tetap dipertahankan.
- `AIExtraction` mendapat `user_id` beserta indeks, foreign key, migrasi Alembic,
  dan jalur persistensi untuk upload URL maupun file.
- Bootstrap database memeriksa tabel, kolom, tipe/nullability, primary key, unique,
  indeks, dan foreign key sebelum melakukan rekonsiliasi/stamp. Kegagalan sinkronisasi
  schema sekarang menghentikan startup.
- Webhook Telegram fail-closed saat secret kosong dan menolak secret yang salah.
- CSP berlaku secara default. Token SPA tidak lagi persisten di `localStorage` dan
  hanya hidup selama sesi tab/browser.
- Query migrasi enkripsi memakai SQLAlchemy Core sehingga identifier di-quote oleh
  dialect, bukan dirangkai sebagai SQL mentah.
- `datetime.utcnow()`, konfigurasi Pydantic v1, generic lama, dan enum string lama
  dimigrasikan ke API Python/Pydantic mutakhir.

Sesuai keputusan produk, enforcement secret webhook WhatsApp sengaja tidak diubah.
Keterbatasan dan konfigurasi yang berlaku didokumentasikan di `docs/setup-whatsapp.md`.

### Toolchain dan delivery

- Frontend: React 19.2.8, React Router 8.3.1, Vite 8.2.2, Tailwind CSS 4.3.3,
  Vitest 5.0.0, Zod 4.5.4, dan dependency lain sesuai lockfile pnpm terbaru.
- TypeScript Native 7.0.2 tersedia berdampingan dengan TypeScript 6.0.2 untuk
  kompatibilitas tool lint/build yang belum mengonsumsi API native.
- Backend dikunci dengan `uv.lock`; runtime utama mencakup FastAPI 0.141.1,
  SQLAlchemy 2.0.52, Pydantic 2.13.5, dan Uvicorn 0.52.4.
- CI memakai Node 24, Python 3.14, pnpm 11.25.0, uv 0.12.9, least-privilege
  permissions, serta action yang dipin ke commit SHA.
- Docker membangun dari kedua lockfile, menjalankan aplikasi sebagai UID 10001,
  memperbaiki ownership volume sebelum turun privilege, dan mengecualikan secret,
  cache, database lokal, virtualenv, serta `node_modules` dari build context.

Dokumentasi versi utama: [React Router changelog](https://reactrouter.com/changelog),
[Vite releases](https://vite.dev/releases), [Tailwind CSS 4.3](https://tailwindcss.com/blog/tailwindcss-v4-3),
[Vitest 5](https://vitest.dev/blog/vitest-5), dan
[TypeScript 7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/).
